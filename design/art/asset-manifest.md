# MANABIT - MASTER ART MANIFEST & LANDING ZONE

**How to use this doc.** This is the drop-in art landing zone for all 100 bits + the non-bit assets. Art lands with **zero code edits**: author `res://art/bits/<id>.glb` (atlas embedded), drop it into `res://art/bits/`, reimport, and it renders on the next Workshop/stage rebuild. Until a bit's `.glb` exists it falls back to the procedural primitive composite (`ui/manabit_stage.gd`) - so the game is never broken, art just gets better one file at a time. `<id>` must equal `PartData.id` **exactly**. Icons are optional (`res://art/icons/<id>.png`, 128×128) - a runtime SubViewport mesh-thumbnail covers cards until a real icon drops in.

**Catalog:** 100 unique bits = 3 cores + 10 hardcoded baseline bodies + 87 themed (across 17 branded families; wave 2 retro-hero families added 2026-07-19). `parts/catalog_extra.json` holds 90 lines (87 themed + the 3 cores duplicated for completeness; the hardcoded base fixtures win id collisions).

## Shared Art DNA (every prompt below is read against this - restate as needed)
- **Tech:** PS1-era low-poly, **300-800 tris/bit** (cores & EPICs ≤~600; chibi Pocketful ≥150). One **point-filtered (NEAREST)** pixel-texture atlas, mipmaps off; **128px** for COMMON/RARE bodies, **256px** for cores & EPICs. Flat / per-vertex lighting, affine-warp friendly.
- **Coherence anchor (all bits):** authored at **LOCAL origin = the socket point**; a chamfered **hex brass snap-socket collar + one warm glow-dot** where it plugs in. Runes are **baked texel detail, never extra geometry**. Neutral T-pose-friendly orientation, centered, plain neutral background.
- **Rarity ladder (material + rune-light, NEVER foil, NEVER color-only):** COMMON = worn-tin `#AEB6B8` frame + 1 dark unlit stamped serial · RARE = brass `#B08D57` frame + a cobalt `#4A90D9` rune-line that lights · EPIC = runed-wood/gold `#C9A24E` frame + amethyst `#B857C9` rune motif + gold flecks + 256px atlas.
- **Coupling (least author burden):** ship a plain good-looking plastic bit. The **engine** paints the affinity soul-glow at the collar - attack ember-rust `#C05A3E` / defense slate-blue `#5A7A9A` / mana flux-teal `#3FA890` - re-tints any material named **`mana_glow`** (toggled by `awake`, for bodies meant to glow their affinity, e.g. Pith), and tints any material named **`frame`** to the rarity color.
- **Tone lock:** warm collectible cozy-craft **toy that happens to be enchanted** - NOT liminal-horror, NOT glowing circuitry, NOT a licensed mecha.
- **family_map.json** (id→family, ship alongside the tree): the 10 hardcoded bodies key `baseline`; the 3 cores key `artificer_first`; the 64 themed key their catalog family. Lets the tinter + mid-tier fallback (`_family_<family>_<slot>.glb`) resolve family without a `PartData` field.
