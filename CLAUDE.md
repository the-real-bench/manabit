# MANABIT - Master Config

## Project
**MANABIT** - an Artificer builder-battler roguelite. You are an **Artificer** (a maker-mage,
the immortal account-level identity) who **assembles a Manabit** - a mortal animated toy-construct -
from stat-bearing parts, binds a crafted **mana core** (its soul + life bar) into it, and wagers it
in turn-based, part-targeted battles: **loot a part off whoever loses**. Core loop: **build → fight →
wager → loot**. Engine **Godot 4.x / GDScript**. Art: **PS1 rendering technique, cozy-craft tone**
(warm, collectible, etched-rune plastic, soft mana-glow - NOT liminal-horror, NOT cyber-circuitry).
Owner: jaxonblazebooks@gmail.com.

**Identity spine (protect this):** Artificer = immortal maker. Manabit = mortal creation. Mana core =
crafted per-build soul + life bar. You always survive; your creations don't.

**Terminology (LOCKED 2026-07-11 by owner):**
- **bit** = a single piece / part. Plural "bits." (Code type is `PartData`/`PartInstance` - an internal name; every *player-facing* word is "bit." Renaming the verified §13 classes is deliberately avoided.)
- **Manabit** = the whole assembled robot, once its bits are bound together. Never call the 3D construct "the bit."
- **Screens are split:** **opening chests (Coffers)** is its OWN screen (the Coffer Nook); **creating Manabits** (assembly) is a separate screen (the Workshop). Do not merge them.

## Conventions
- **NO em-dashes or en-dashes anywhere in this project (owner directive 2026-07-18) - use plain hyphens only.** Applies to code, comments, UI strings, and docs.
- Prefer editing existing files; **don't create markdown docs unless asked**. Large artifacts → **G:**.

  write fight state onto the shared `.tres` (see §13.2).
